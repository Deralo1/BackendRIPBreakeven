# Лабораторная работа №1 по курсе "Разработка интернет-приложений"
Расчет точки безубыточности нового продукта. Услуги - виды затрат (постоянные: аренда, оклады; переменные: сырье, сдельная зарплата), заявка - расчет точки безубыточности в единицах продукции и в денежном выражении по списку переменных и постоянных затрат.
